# Images

All About-page imagery is referenced from `index.js`.

To use your own photography:

1. Copy your file here, e.g. `showroom.jpg`.
2. In `index.js`, add `import showroom from './showroom.jpg';`
3. Swap the Unsplash string for the imported variable.

Recommended sizes:

| Key         | Purpose                    | Suggested size |
|-------------|----------------------------|----------------|
| `aboutHero` | Full-width hero banner     | 1920 x 800     |
| `showroom`  | Rounded showroom card      | 1600 x 1000    |
| `director`  | Managing Director portrait | 900 x 1100     |
